# VASP-NEB-Calculations

This repository contains the workflow and scripts used to perform **Climbing Image Nudged Elastic Band (CI-NEB)** calculations with **VASP** to determine the **vacancy migration energy barrier (MEB)** in three Cu-based alloys.

## Overview

* **System Setup:**
  A 2×2×2 face-centered cubic (FCC) supercell containing 64 atoms was used. Supercells were generated using a Python script that randomly placed the constituent atoms according to the specified concentrations.

* **Initial Relaxation:**
  Each alloy system was fully relaxed to obtain a stable reference structure.

* **Vacancy Creation:**
  A second script was used to remove a central Cu atom from the supercell to create a vacancy. The system was then relaxed again (volume fixed). Additional configurations were generated by creating vacancies at each of the 12 nearest-neighbor (NN) sites of the original vacancy location.

* **CI-NEB Setup:**
  CI-NEB calculations were performed using:

  * Initial state: relaxed structure with the central vacancy
  * Final states: relaxed NN-vacancy configurations
    Five intermediate images were used to construct the migration pathway and obtain the MEB.

---

## Workflow

Follow these steps to reproduce the CI-NEB calculations:

1. **Generate Supercells**
   Run the `Pristine_structure` script to create supercells with desired compositions.

2. **Relax the Pristine Structure**
   Perform a full relaxation using the VASP input file: `INCAR_rp`.

3. **Generate Initial and Final NEB Structures**
   Run the Jupyter notebook `NEB_structures.ipynb` to generate the initial and final structures for the NEB calculation.

4. **Relax NEB Images**
   Relax the NEB images using `INCAR_pNEB` in a VASP calculation to prepare for the full NEB run.

5. **Run the NEB Calculation**
   Perform the NEB calculation using the input file `INCAR_NEB1`.

---

## Extracting Results

After the NEB run is complete, use the provided script `ene_sum_complete.sh` to extract and analyze the MEB profile.
